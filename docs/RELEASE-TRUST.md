# Release trust

Every release is versioned and must publish these files alongside its archives:

- `MANIFEST.json`: exact tracked release inputs and SHA-256 hashes.
- `SHA256SUMS`: shell-friendly digest list.
- `SBOM.spdx.json`: component inventory.
- `PROVENANCE.json`: repository, commit, workflow, and build time.
- `SHA256SUMS.sig`: Sigstore/cosign signature generated by the release workflow.

Build metadata can be regenerated locally with:

```bash
npm run release:manifest
```

Do not trust a hash served by the same unverified download location as an artifact. Verify the signed release, repository tag, commit, and provenance together.
