# Contributing

Thanks for improving the marketplace.

## Plugin requirements

- Place each plugin in `plugins/<plugin-name>/`.
- Include `.codex-plugin/plugin.json` with a matching, hyphenated plugin name.
- List the plugin in `marketplace.json` using `./plugins/<plugin-name>` as its source path.
- Include a short README in the plugin folder describing purpose, setup, and usage.
- Do not commit secrets, private credentials, or personal data.

## Pull requests

Keep pull requests focused. Explain what the plugin does, how it was validated, and any service permissions it requires.
